# Pikachu asset provenance and movement correction

Selected page: https://sprites.pmdcollab.org/#/0025?form=0

Downloaded package: https://spriteserver.pmdcollab.org/assets/0025/sprites.zip

Retrieved 2026-10-13. Original package: `Pikachu-PMDCollab.zip`.
The site's public GraphQL API identifies the base form with an empty form path,
primary credit CHUNSOFT, and this download URL. Its animation URLs point to
PMDCollab/SpriteCollab's `sprite/0025` directory. Changing to the selected page
therefore changes the acquisition route, not the underlying character artwork.
Server assetsCommit at verification: `0a2f8383a6113260c3748d557ff4963dd66dd330`.

Imported Walk, Idle, Charge animation/Shadow PNGs and AnimData.xml into
`Assets/Resources/Pikachu`. Preserved the existing original credits.txt.
Shadow images are alignment metadata, not displayed art; their green center
marks determine the per-frame pivot. They alone need readable texture imports.

Visual inspection of all eight original Walk rows confirms:

| Row | Direction | Keys |
| --- | --- | --- |
| 0 | South | S |
| 1 | Southeast | S+D |
| 2 | East | D |
| 3 | Northeast | W+D |
| 4 | North | W |
| 5 | Northwest | W+A |
| 6 | West | A |
| 7 | Southwest | S+A |

Previous code assumed the opposite horizontal ordering, so it walked right
while displaying a left-facing sprite (also affecting diagonal movement).
`Previews/Pikachu-SourceRows.png` provides the visual reference for the regression
checks. The source Idle includes a hopping action; the playable idle deliberately
holds its grounded first frame to avoid apparent unintended movement.

Electricity is generated by game code in `PikachuElectricity.cs`: brief trailing
arcs, charging sparks, two short branched contacts, ground arcs and fading motes.
No external VFX assets or shaders are required.

Validation completed in Unity 6000.5.7f1:
- Editor regression: eight directions and source rows, normalized diagonal speed,
  30/144 Hz consistency, stopped facing, court bounds, intro input lock,
  monotonic entry/center arrival, effect cleanup and replay.
- Play Mode smoke test: real Awake/Update entrance, movement, return to menu,
  no player left in menu, fresh arena entry, and replay. No game runtime errors.
- Visually checked the enlarged source sheet and rendered running/strike/ready
  views. `Previews/Pikachu-Entrance.gif` shows the sampled intro at 24 fps.

Logs: `Previews/PikachuCheck.log` and `Previews/PikachuPlayModeCheck.log`.
The automated checks exercise the same movement method as WASD; manual keyboard
feel has not been assessed by a human tester.
